06 · Keyboard architecture

Keyboard-first intent, decentralized impl

Current listeners work locally but lack scope, priority, conflict detection, remapping, unified help.

Current

Multiple event owners

MainLayout: global search, settings, create, rename, terminal, Escape.

FileList: arrows, selection ranges, Enter/open.

usePreview: Space, Escape, arrows while preview open.

keyboard.js: registry/helpers exist, but central registry is unused.

MainLayout.jsx:505–560 · FileList.jsx:340–434 · usePreview.js:89–142 · utils/keyboard.js:39–185
Target

Central command router

Raw key → normalized chord → active focus scope → command ID → handler.

Scopes: global, explorer, preview, terminal, modal, text-input. Define this contract before adding feature listeners.

Priority: modal → focused pane → workspace → global.

Bindings become config, command palette entries, shortcut docs from one registry.

Immediate rule: never add another document-level listener. Build router first. Current MainLayout handler has no text-input guard; shortcuts may activate while user types.
07 · Terminal

Command console now; PTY adapter later

Current terminal executes complete commands and buffers output. It is not terminal emulation.

Current

React command console

Custom prompt, history, reverse search, built-ins, execution state. Commands call execute_command_improved or timeout variant.

Backend starts user shell with -c, captures stdout/stderr through pipes.

Terminal.jsx:18–30, 138–245 · command_exec_commands.rs:69–115
Target

Terminal adapter contract

createSession · write · resize · signal · close · streaming events.

Built-in adapter owns PTY + process tree. Future adapters can bridge external terminals while workspace integration stays stable.

T1 · Shared cwd

Explorer→terminal: explicit sync or new-session cwd. Terminal→explorer: trusted cwd event, not prompt scraping.

T2 · Selected paths

Insert/send selected paths using adapter-aware shell quoting. Never raw concatenation.

T3 · Lifecycle

Session IDs, process ownership, streaming backpressure, resize, signal, exit status.

Security boundary: shell IPC executes arbitrary commands by design. Frontend compromise means host command execution. Maintain strict CSP, dependency integrity, capability gating. Current UI cancellation rejects local promise but does not prove child process termination.
08 · Preview pipeline

Strong format coverage, unsafe large-file path

Tagged Rust payload maps directly to React renderer.

Focused itemSpace / arrows
Transportlocal or SFTP
MIME detectcontent + ext
Payloadtagged enum
Renderernative webview UI
Navigatenext preview

Direct data

Local + SFTP image/PDF use base64 data URI. Text returns decoded, capped content.

Asset path

Local video/audio return path via Tauri asset protocol. SFTP video/audio currently return Unknown.

Metadata

Local folder returns child count, shallow size, modified time. Transport support differs.

Priority redesign: local + SFTP files above caps encode only prefix bytes as image/PDF data URI → malformed payload likely. Replace with transport-aware thumbnail/stream API, capability matrix, cancellation token, bounded cache. Restrict asset protocol scope now set to */**.

11 · Suggested roadmap

Stabilize → unify → scale → extend

Sequence minimizes rewrite risk. Terminal plugins come after workspace, IPC, PTY contracts stabilize.

R1 · Secure

Close critical boundaries

  1. OS-backed creds.
  2. SFTP host keys.
  3. Delete semantics.
  4. Asset scope.
  5. Shell capability review.
R2 · Stabilize

Make current app trustworthy

  1. Fix IPC mismatches.
  2. One workspace state.
  3. Frontend CI gates.
  4. Perf baselines.
  5. Typed IPC contract.
R3 · Contracts

Define seams before engines

  1. Command/keymap router.
  2. Transport interface.
  3. Preview handler API.
  4. Terminal adapter API.
  5. Capability matrix.
R4 · Engines

Scale then extend

  1. Paged/lazy dir load.
  2. Preview streaming.
  3. PTY adapter.
  4. External adapter.
  5. Cross-platform tests.
